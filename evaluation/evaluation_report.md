## 2. 표본 검수 (가이드 6-5)

- 표본 크기 / 추출 방식(층화 기준) / 시드: 100건 / 유사 기사 그룹 대표 기사 중 LLM 감성 × 카테고리 층화 / 시드 42
- 검수자: 팀원 2명(A, B). LLM 결과를 보지 않고 각자 라벨링. 원문을 열어 판단한 건수 A 13건, B 0건
- 라벨 기준: 감성(가이드 6-3), 카테고리(가이드 1-3). 특수값 `판단불가`(제목·요약으로 판단 불가), `관련없음`(산업·법인과 무관)
- **합의(adjudication) 생략**: 의견이 갈린 73건(감성 28, 카테고리 35, 관련 여부 10)을 합의하지 않았다.
  그래서 정확도는 각 검수자의 라벨을 정답으로 따로 계산한 **두 값의 범위**로 보고한다.
  두 검수자가 일치한 항목만으로 계산한 값(감성 0.885, 카테고리 0.833)은 쉬운 항목에 치우쳐 인용하지 않는다.

| 지표 | 값 |
|---|---|
| 감성 정확도 | 표본 0.678\~0.848 (B n=90 / A n=99), 모집단 가중 추정 **0.751\~0.802** |
| 카테고리 정확도 | 표본 0.622\~0.677 (B n=90 / A n=99), 모집단 가중 추정 **0.694\~0.795** |
| 분류별 정확도 | 합의 생략으로 산출하지 않음 (합의된 항목만의 값은 `llm_validation_report.md` 2절 — 높게 편향) |
| 검수자 간 일치율 | 감성 0.685 (κ 0.522), 카테고리 0.607 (κ 0.459), n=89 |
| 이슈 요약 사실 일치 비율 | **0.897** (n=97, 판정 시트 1부 — LLM 요약이 입력한 제목·요약에 없는 내용을 더했는지) |
| 관련없음 판정 | A 0건, B 10건 — 뉴스 정제가 무관 기사를 남겼을 가능성. 검수자 간 판단이 갈려 확정하지 않음 |
| 판단불가 | A 1건 (여러 뉴스를 묶은 종합 기사) |

해석:
- LLM과 각 검수자의 일치(0.62\~0.85)가 검수자끼리의 일치(0.61\~0.69)와 비슷하거나 높다. 카테고리 경계가 사람에게도 모호하다는 뜻이며,
  주로 갈린 곳은 인증 서비스(SOC·ISO)·사이버보안 교육·AI 거버넌스 기사(규제 / 기술 / 인프라)와 행사·세미나 기사의 감성(중립 / 긍정)이다.
- 모집단 가중 추정은 층화 표본을 전체 분류 기사의 감성×카테고리 분포로 되돌린 값이다. 전체 기사 기준으로는 이 값을 인용한다.
- 같은 사건을 다른 제목으로 쓴 기사가 표본에 함께 들어간 경우가 있다(B 표시 4건). 유사 기사 묶기가 제목이 다른 기사는 잡지 못하는 한계다.

## 3. RAG 평가 (가이드 7, 10)

최종 측정 2026-11-17 (첫 측정 11-16). 상세 수치는 `evaluation/rag_eval_report.md`(`scripts/evaluate_rag.py`로 생성), 질문은
`evaluation/rag_test_questions.json`. 답변·인용 전문은 `data/processed/rag_eval/answers.csv`(로컬)에 있다.

- 구성: 임베딩 `text-embedding-3-large`, LLM `gpt-6-luna`(temperature 미지정 = 모델 기본값), 프롬프트 `rag-v4`, k=8, 청크 900자(겹침 150)
- 인덱스: 원문이 있는 DART 공시 146건 (법인 자체 회계법인사업보고서 + Big4가 제출한 고객사 감사보고서 원문 표본),
  청크 10,126개 (자체 2,305 / 고객사 7,821, 11-16 구축 기준 — 11-17 절 경로 적용은 분할 규칙이 같아 청크 수는 그대로로 보나 다시 세지 않음).
  감사보고서 10건 이상에 같은 문장으로 나오는 표준 문단 498종은 청크 전에 제거
- 임베딩 비용: 실제 청구액 미확인. 실행 전 추정치(글자 수 ÷ 1.3 기준)는 11-16 구축 3회 합계 약 $2.37
  (최초 $0.90, 표준 문단 제거 후 감사보고서 재임베딩 $0.63, 청크 방식 변경 후 전체 재임베딩 $0.85). 11-17 절 경로 적용 재임베딩의 추정치는 기록하지 않음

  기준을 0.55~0.57로 올리면 이 11개는 모두 1차에서 갈리지만 같은 질문에 맞춘 값이 되므로 택하지 않았다.

| 2025-03-10 주 급증 배경 | 채택 2에 예시로 흡수 |

- 검수에서 확인한 점(감성): 감성은 **기사 논조**(사업 환경에 우호적인지) 기준이라, 법인이 감사인·협력사로만 등장한 기사도
  기사 논조를 따른다(예: 고객사의 손실을 다룬 기사에 새 감사인으로 등장한 경우 부정). 법인에 대한 평가가 아니며,
  같은 법인도 해마다 크게 달라(딜로이트안진 2025년 73.7% → 2026년 32.5%) 한 해 값으로 법인을 비교하지 않는다.

## 5. 남은 한계

### LLM 분류 (Day 4)
- 검수자 간 일치가 보통 수준(κ 0.46~0.52)이고 의견이 갈린 73건을 합의하지 않았다. 정확도는 두 검수자 기준 범위로만 말할 수 있다.
- 카테고리 경계가 겹친다: 인증 서비스(SOC·ISO)·사이버보안 교육·AI 거버넌스(규제 / 기술 / 인프라), 행사·세미나 감성(중립 / 긍정).
  → 개선: 경계 사례를 정의에 추가(v2 프롬프트·검수 기준 공통)하고 새 표본으로 다시 잰다 (같은 표본으로 고치면 정확도가 부풀려진다).
- 입력이 제목+요약뿐이라 맥락이 부족한 기사가 있다 (A가 13건은 원문을 열어 판단, 판단불가 1건).
- 유사 기사 묶기가 제목이 다른 같은 사건 기사를 잡지 못한다 (표본 안 4건).
- B가 관련없음으로 본 10건은 뉴스 정제(관련 기사 판정)의 오탐일 수 있으나 확정하지 않았다.
- temperature를 모델 기본값으로 두어 같은 기사도 실행마다 결과가 다를 수 있다. 비용은 미확인.

### 결론 문장 (Day 7)
- 초안은 1회 생성 결과이며(temperature 기본값) 다시 실행하면 문장이 달라질 수 있다. 최종 문장은 사람이 고친 결과다.
- 사실 목록에 없는 내용(공시 수치 추출, 법인 대상 감성)은 결론으로 다루지 않았다.
- 법인 대상 감성(기사 속 해당 법인을 어떻게 묘사하는가)은 측정하지 않았다. 바꾸려면 프롬프트 v2, 전체 재분류, 표본 재검수가 필요하다.
- 유사 기사 묶기가 제목을 바꿔 쓴 같은 사건 보도를 잡지 못한다(급증 주 근거 기사 3건이 모두 같은 협약 보도인 사례:
  2025-03-10 주, 2026-10-19 주 — 영문·한글 표기 차이 포함). 키워드별 사건 수가 실제보다 많게 셀 수 있다.

### RAG (Day 5)
- **인용 검증은 답변 전체의 검증이 아니다.** 원문에 있는 인용 1개만 통과해도 답변 문장 전체가 표시됐다.
  2026-11-19부터 답변의 숫자가 인용 원문에 없으면 "확인 필요"로 표시한다(평가 CSV `unverified_numbers` 열). 위 평가 수치는
  이 장치 이전의 측정이며, 숫자가 없는 주장은 여전히 검사하지 않는다.
- **같은 사업연도의 원본·정정본과 연도별 공시가 함께 인덱싱**되어 비슷한 청크가 검색 자리를 나눠 갖는다.
  11-16에는 Q02가 2022년 정정본으로 답했고(11-17 해결), 11-17에는 Q05에서 한영을 2025.06 값으로 답했다.
  → 개선: 사업연도별 최종 정정본만 인덱싱.
- **질문과 공시의 용어가 다르면 검색이 실패**한다. Q04는 '조치·제재'로 물었고 공시 절 제목은 '감리결과'다.
  키워드(BM25) 하이브리드·LLM 리랭킹(6절)으로도 Q04는 풀리지 않았다(겹치는 글자가 없음). → 개선: 동의어 사전 또는 질문 확장.
- **여러 법인을 한 번에 묻는 질문**은 k=8 안에 4개 법인이 모두 들어오지 않을 수 있다 (Q05 안진 누락). → 개선: 법인별 검색 후 합치기.
- 평가 질문 11개로 거절 기준값과 청크 방식을 조정했으므로 위 수치는 새 질문보다 낙관적이다.
- 모델이 temperature 기본값만 허용해 같은 질문의 답이 실행마다 다를 수 있다 (11-17 같은 안진 감사실적 질문에서
  인용 12개 / 2개 — 숫자는 같았다).
- 청크마다 법인명이 든 문맥 줄이 붙어, 법인명을 언급한 무관한 질문도 유사도가 0.5 안팎까지 오른다.
- 고객사 감사보고서 130건 중 1건은 고객사명을 확인하지 못해 '고객사 미확인'으로 표시된다.
- 고객사 감사보고서는 **2026년 3월 제출분 표본(법인당 30건)**만 원문이 있어, 그 밖의 고객사 질문은 거절된다.

## 6. 심화: 공시 QA 검색 방식 비교 (2026-11-18)

상세: `evaluation/rag_search_comparison.md`, 방식별 리포트 `rag_eval_vector.md` / `rag_eval_hybrid.md` / `rag_eval_hybrid_rerank.md`.

- 방식: `vector`(기존) / `hybrid`(+ BM25 키워드, 글자 2-gram, RRF 결합) / `hybrid_rerank`(hybrid 후보 20개를 LLM이 재정렬해 8개 사용).
  1차 거절은 세 방식 모두 벡터 유사도 0.50으로 같게 두었다.
- 질문: 기존 11개(base) + 검색 고도화 뒤 추가한 6개(holdout, 공시 절 제목과 다른 말로 묻는 질문 4 + 근거 없음 2).
  holdout은 설정을 맞추는 데 쓰지 않았다. 판정은 DART 원문 대조(거절 = 0).

| 방식 | base 정답 | holdout 정답 | 전체 정답 | 근거 없는 질문 거절 |
|---|---|---|---|---|
| vector | 7/8 | 3/4 | 10/12 | 5/5 |
| hybrid | 7/8 | 2/4 | 9/12 | 5/5 |
| hybrid_rerank | 7/8 | **4/4** | **11/12** | 5/5 |

- 세 방식 모두 답한 질문은 전부 정답이었고, 차이는 답할 수 있는 질문을 거절했는지에서 났다.
- hybrid_rerank만 H02(징계, 공시는 '징계내역')를 찾았다. hybrid만 쓰면 H04(법적 분쟁, 공시는 '소송')를 거절해 vector보다 낮았다.
  키워드만 더하면 관련 없는 청크도 같이 올라와 순위가 섞이고, 리랭킹이 그 순서를 바로잡은 것으로 보인다(해석).
- Q04(감독기관 조치, 공시는 '감리결과')는 세 방식 모두 실패했다.
- Q05는 이번에 세 방식 모두 정답으로 판정됐다(11-17 측정은 오답). 모델이 temperature 기본값이라 실행마다 답이 달라질 수 있고,
  판정자도 다를 수 있다. 같은 질문의 결과가 바뀔 수 있다는 재현성 한계로 기록한다.
- 한계: holdout이 4문항뿐이라 한두 문항 차이는 우연일 수 있다. hybrid_rerank는 질문마다 LLM 호출이 1회 늘어난다(실제 비용 미확인).

## 7. 심화: 기간(분기)별 이슈 자동 요약 (2026-11-18)

- 방법: 분기마다 기사가 많은 사건(유사 기사 그룹) 상위 8개를 저장된 분류 결과(카테고리·감성·키워드·한 줄 요약)로 묘사하고,
  그 분기에 사람이 기록한 급증 배경을 더해 LLM이 headline 1문장과 이슈 1\~3개를 썼다(`gpt-6-luna`, prompt `issue-v1`).
  LLM에는 기사 제목·URL을 보내지 않았고, 이슈가 인용한 사건 번호로 근거 기사를 코드가 연결했다.
- 대상: 2023-Q4(11월부터) \~ 2026-Q4(10월까지) 13개 분기, 분기당 호출 1회. 실제 비용 미확인.
- 검수: 두 사람이 근거 기사를 열어 대조하고, 필요한 문장은 직접 고친 뒤 O/X. **13개 분기 모두 두 사람 승인으로 적재**(거절 0).
  - 확인된 수정 사례: 2025-Q4의 한 이슈가 업무협약(MOU) 단계인데 서비스를 이미 제공하는 것처럼 쓰여 "~하기로 했다"로 고침.
    같은 협약을 다룬 기사 두 건이 다른 그룹으로 나뉘어 있어 근거에 둘 다 넣음.
  - 2026-Q2는 이슈 2개로 유지(1\~3개 허용).
  - 분기별 수정 건수는 따로 기록하지 않았다.
- 관찰(요약 문장 기준): headline 13개 중 10개에 'AI'가 들어가고, 2024-Q3부터 2026-Q3까지 9개 분기 연속이다.
  기사가 많은 사건을 중심으로 쓴 요약이므로 보도 노출의 흐름이며, 법인의 사업 비중을 뜻하지 않는다.
- 한계: 요약의 입력은 LLM 분류 결과(한 줄 요약)라 그 정확도(요약 사실 일치 0.897)의 영향을 받는다. 다시 실행하면 문장이 달라질 수 있다.
  요약 입력과 저장된 요약은 네이버 뉴스 파생물이라 프로젝트 종료 시 삭제한다.
